Meapi API Key 余额查看器

使用：
1. 双击：启动余额查看器.bat
2. 本机打开：http://127.0.0.1:8787
3. 给别人看：把黑色窗口里的“局域网访问”地址发给对方，例如 http://192.168.x.x:8787
4. 如果 Windows 防火墙弹窗，允许 Python 访问“专用网络”。

当前额度换算规则：
- 平台真实 Key 额度：30
- 对外展示购买额度：50
- 线性换算比例：50 / 30 = 1.6666667
- 平台真实消耗 3，网页显示消耗 5。
- 平台真实剩余 15，网页显示剩余 25。
- 平台真实用完 30 时，网页显示 50 也刚好用完。

安全说明：
- 完整 API Key 保存在 config.json。
- 网页源码和 /api/usage 返回值不会显示完整 API Key，只显示打码后的 key。
- 如果别人能访问这个文件夹，就能看到 config.json 里的 key；只分享网页地址，不要分享文件夹。
- 不建议直接部署成公网网页；如果必须公网部署，建议加访问密码或反向代理鉴权。

修改配置：
- public_quota_limit：对外展示额度，现在是 50。
- real_quota_limit：平台真实额度，现在是 30。
- scale_usage_to_public_quota：是否启用线性换算，现在是 true。
- port：网页端口，现在是 8787。
